# Code of conduct

Network Canvas is a small open-source project maintained in spare time. Be kind, be concrete, assume good
faith. Disagreement about design is welcome; personal attacks, harassment or discrimination of any kind are
not, in issues, pull requests, discussions or anywhere else the project is represented.

Maintainers may edit, lock or remove content and block accounts that break this. To report a problem
privately, email the maintainer listed in `package.json`.
