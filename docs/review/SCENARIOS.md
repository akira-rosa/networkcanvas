# Review scenarios

Four people, six jobs and three reference projects. Every review track uses them, so findings can be
reproduced by anyone with the repo.

## People

| Persona | Context | What they need from Network Canvas |
|---|---|---|
| **OT engineer** (Ana) | Documents a production cell she commissions; knows PROFINET, VLANs, the PLC programs | Draw fast from an inventory, get addresses and ports right, print the cell sheet for the cabinet |
| **Integrator** (Bruno) | Hands an as-built package to a client at the end of a project | A complete, consistent sheet set (A3, title block, revisions), cable schedule, IP plan, bill of materials, a file the client can open |
| **Auditor** (Carla) | Reviews segmentation for IEC 62443 / insurance | See zones, conduits and what crosses them; trust that the drawing matches reality; know when it was last changed and by whom |
| **Maintenance technician** (Diego) | Fixes a stopped line at 3 a.m., tablet in hand | Find the device, its port, cable and IP in seconds; read-only; works offline in the plant |

## Jobs (end-to-end walkthroughs)

1. **Start from nothing** — Ana creates a topology for Cell 3, adds ~40 devices, links them port to port, assigns VLANs and IPs, clears the checks.
2. **Start from an inventory** — Ana imports a CSV of 40 devices (name, model, IP, cabinet) and arranges them.
3. **Deliver** — Bruno prints the plant as an A3 sheet set with title block and revision, exports cable schedule, IP plan and inventory, and sends the file.
4. **Revise** — three months later Bruno opens the file, replaces a switch, re-cables four devices, records revision B and shows the client what changed.
5. **Audit** — Carla opens the plant file and answers: which zones exist, what connects the OT DMZ to the lines, which devices have no owner or firmware recorded.
6. **Troubleshoot** — Diego opens the interactive HTML on a tablet, finds `L4-VFD3`, sees its switch port, cable ID and IP.
